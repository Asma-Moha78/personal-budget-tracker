My Budget Tracker
Project Description

This is my Budget Tracker project. I continued building on my Week 1 project and improved it during Week 2 and Week 3.

The project includes an expense table, an improved expense form, multimedia content, interactive elements, advanced CSS selectors, a consistent color palette, custom typography, and improved visual styling.

Files

index.html - Contains the structure and content of the Budget Tracker.

style.css - Contains the styling, visual design, and advanced CSS selectors.

README.md - Explains the project and its features.

Week 3 Features
Color Palette

I created a consistent and professional color palette for the Budget Tracker.

The design uses:

A light background color

Dark green for headings and table headers

Green for buttons and interactive elements

Light green for alternating table rows

White for the main content cards

Soft borders for structure

I used CSS variables to keep the colors consistent throughout the project.

Typography

I added Google Fonts to improve the readability and visual hierarchy of the application.

Playfair Display is used for headings.

DM Sans is used for body text, labels, form elements, buttons, and table content.

This creates a clear difference between headings and regular content.

Table and Form Styling

I improved the existing expense table and Add Expense form using CSS.

The styling includes:

Proper spacing

Padding inside form inputs

Padding inside table cells

Borders

Rounded corners

Styled table headers

Alternating row colors

Table row hover effects

Focus effects for form inputs

Consistent button styling

A green button with a hover effect

CSS Box Model

I used the CSS Box Model to create clear separation between different parts of the application.

I applied:

Margin to separate sections

Padding to create space inside cards and form elements

Borders to define sections and table cells

Border-radius to create rounded corners

Box shadows to create visual separation

The Add Expense form and Expense Table are displayed as distinct card-style sections.

Responsive Design

I added a responsive media query so the Budget Tracker can adapt better to smaller screens.

The layout adjusts the page padding, table font size, and card spacing when the screen width becomes smaller.

How to Run

Open the index.html file in a web browser to view the Budget Tracker.
