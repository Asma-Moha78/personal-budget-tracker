My Budget Tracker
Project Description

This is my Budget Tracker project. I continued building on my Week 1 project by adding an expense table, an improved expense form, multimedia content, an interactive section, and advanced CSS selectors.

Files

index.html - Contains the structure and content of the Budget Tracker.

style.css - Contains the styling and advanced CSS selectors.

README.md - Explains the project and its features.

Week 2 Features
Expense Table

I replaced the "No expenses yet" message with an HTML table.

The table uses:

<table>

<thead>

<tbody>

<tr>

<th>

<td>

The table contains five sample expenses with their name, amount, category, and date.

Add Expense Form

I upgraded the expense form by adding:

Expense name input

Amount input

Category dropdown

Date input

Add Expense button

The category dropdown contains five options:

Food

Transport

Rent

Entertainment

Other

All form inputs have unique IDs.

Multimedia

I added a budget tracker image using the <img> element.

I also embedded a budgeting video using an <iframe>.

Interactive Elements

I added a <details> and <summary> section that explains how to use the tracker.

I also added a hover effect to the expense table rows and a pointer cursor to the Add Expense button.

Advanced CSS Selectors

I used several advanced CSS selectors, including:

Descendant selector

Direct child selector

:nth-child() pseudo-class

:not() pseudo-class

:focus pseudo-class

:hover pseudo-class
